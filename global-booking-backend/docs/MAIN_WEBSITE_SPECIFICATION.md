# Main Website Specification

This document defines future public-site requirements without selecting a visual design or implementing pages.

## Planned areas

- GLOBAL BOOKING homepage.
- Solutions by Industry index.
- Individual landing pages for all configured industries.
- Tenant and industry-aware booking entry points.
- QR-based booking entry points.
- Request Demo and Get Started actions.
- Responsive and accessible presentation.

## Configuration behavior

Landing pages must resolve category names, service-recipient language, staff language, booking availability, and route metadata from centralized configuration. Medical experiences must display Patient terminology. Shared templates must not hardcode Customer or Client.

## Security and privacy

Public routes must not reveal tenant-private settings, patient records, medical information, administrative data, or internal identifiers unnecessarily. Future forms require input validation, abuse controls, privacy notices, and explicit authorization before collecting sensitive information.

## Deferred decisions

Visual theme, layouts, components, content management, analytics, authentication, forms, SEO implementation, QR processing, and hosting are not part of Phase 1.
